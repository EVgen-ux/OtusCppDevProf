# Курс "C++ Developer. Professional" Домашнее задание №8 “Boost”

Утилита для быстрого поиска дублирующихся по содержимому файлов с использованием библиотеки Boost.

## Установка и запуск
Установите библиотеку Boost:

```
sudo apt-get install libboost-all-dev
```

Скачайте .deb пакет, соответствующий релизу. Введите следующие команды:

```
sudo dpkg -i  bayan-0.0.X-Linux.deb 
```
(где Х - номер релиза)

```
bayan [...]
```



## Флаги, которые можно указать при запуске пакета `bayan`:

| Опция         | Короткая | Описание                                   | По умолчанию |
| ------------- |:--------:| :-----------------------------------------:|:------------:|
| --help        | -h       | Показать справку                           |              |
| --include     | -i       | Директории для сканирования                |              |
| --depth	    | -d       | Глубина сканирования (0 = только текущая)  |  0           |
| --pattern	    | -p       | Паттерны имен файлов для включения         |              |
| --min-size	| -s       | Минимальный размер файла в байтах          |  1           |
| --block-size	| -b       | Размер блока для хэширования в байтах      |  4096        |
| --algorithm	| -a       | Алгоритм хэширования: crc32, md5           |  md5         |


## Использование
### Базовый синтаксис

```
bayan [ОПЦИИ] ДИРЕКТОРИЯ...
```
### Примеры использования

Найти все дубликаты в директории:
```
bayan -i ~/Docs
```
Найти дубликаты изображений с определенными паттернами:
```
bayan -i ~/Photo -p "*.jpg" -p "*.png" -p "*.jpeg"
```
Сканирование с исключениями и ограничением глубины:
```
bayan -i ~/ -e ~/Загрузки -e ~/.cache -d 3
```
Найти большие дубликаты с определенным алгоритмом:
```
bayan -i /data -s 1048576 --algorithm md5 -b 8192
```

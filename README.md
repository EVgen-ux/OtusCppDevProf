# Курс "C++ Developer. Professional" Домашнее задание №10 “Асинхронная сетевая обработка команд”

C++ библиотека для асинхронной обработки и логирования пакетных команд с поддержкой динамических блоков и сетевого взаимодействия.

## Возможности

- **Асинхронная обработка**:  Сервер принимает команды по TCP с использованием Boost.ASIO
- **Работа с несколькими клиентами**: Поддержка множества одновременных подключений
- **Динамические блоки команд**: Поддержка вложенных блоков с использованием разделителей `{` и `}`
- **Двойной вывод**: Одновременный вывод в консоль и запись в файлы логов
- **Потокобезопасность**: Разработана для многопоточных сред
- **Настраиваемый размер блока**: Регулируемый размер пакета для регулярных команд


## Обзор API

```cpp
namespace AsyncBulk {
    ContextID connect(size_t block_size);
    void receive(ContextID context_id, const std::string& command);
    void disconnect(ContextID context_id);
    void shutdown();
}
```

## Сетевой протокол
Сервер принимает команды построчно через TCP соединение. Каждая команда должна заканчиваться символом новой строки (\n).

## Установка и запуск

### Установка из пакета

Скачайте .deb пакет, соответствующий релизу. Введите следующие команды:

```
sudo dpkg -i  HW010-0.0.X-Linux.deb 
```
(где Х - номер релиза)

### Запуск сервера
```
bulk_server <port> <bulk_size> 
```
#### Параметры:

`port` - номер TCP порта для входящих соединений

`bulk_size` - размер блока команд

#### Пример:
```
bulk_server 9000 3
```

### Тестирование
Для отправки команд на сервер используйте утилиту nc (netcat)
Откройте новый терминал и отправляйте команды:

```
seq 0 9 | nc localhost 9000 &

# Отправка команд из файла
nc localhost 9000 < commands.txt &

# Одновременная отправка
seq 0 9 | nc localhost 9000 &
seq 10 19 | nc localhost 9000 &
```

### Завершение работы
Для завершения работы сервера нажмите Ctrl+C в терминале, где он запущен.

# Курс "C++ Developer. Professional" Домашнее задание №13 "Компьютерное зрение”

Проект реализует инференс ML модели компьютерного зрения для классификации изображений предметов гардероба по типу.

В качестве набора данных использetncz Fashion MNIST. В данном наборе данных представлены изображения в разрешении 28х28 пикселей. Каждый пиксел кодируется одним байтом, который задает оттенок серого цвета (0 черный, 255- белый).

## Установка и запуск

### Установка из deb пакета

Скачайте .deb пакет, соответствующий релизу. 

Введите следующие команды:

```
sudo dpkg -i  HW13-0.0.X-Linux.deb 
```
(где Х - номер релиза)

### Запуск
```
./fasion_mist <test.csv_path> <model_path> 
```
#### Параметры:

    <test.csv_path> - путь к CSV файлу с данными

    <model_path> - путь к модели



#### Пример

```
./fasion_mnist ~/Otus/HW13/12_CV/fashion-mnist_train.csv ~/Otus/HW13/12_CV/saved_model/
```

## Удаление
```
sudo dpkg -r hw13
```

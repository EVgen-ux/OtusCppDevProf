# Курс "C++ Developer. Professional" Домашнее задание №9 “Многопоточная асинхронная обработка команд”

C++ библиотека для асинхронной обработки и логирования пакетных команд с поддержкой динамических блоков.

## Возможности

- **Асинхронная обработка**: Команды обрабатываются параллельно с использованием нескольких рабочих потоков
- **Динамические блоки команд**: Поддержка вложенных блоков с использованием разделителей `{` и `}`
- **Двойной вывод**: Одновременный вывод в консоль и запись в файлы логов
- **Потокобезопасность**: Разработана для многопоточных сред
- **Настраиваемый размер блока**: Регулируемый размер пакета для регулярных команд


## Обзор API

```cpp
namespace AsyncBulk {
    ContextID connect(size_t block_size);
    void receive(ContextID context_id, const std::string& command);
    void disconnect(ContextID context_id);
    void shutdown();
}
```

## Установка и запуск


Скачайте .deb пакет, соответствующий релизу. Введите следующие команды:

```
sudo dpkg -i  HW09-0.0.X-Linux.deb 
```
(где Х - номер релиза)


Для запуска демонстрационной программы:
```
./bulk_demo
```

Для запуска программы и ввода команд:
```
./bulk_client [...]
```

sudo dpkg -r HW09

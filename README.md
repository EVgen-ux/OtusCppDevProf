# Курс "C++ Developer. Professional" Домашнее задание №5 “Editor”

## Описание проекта

Каркас графического векторного редактора, реализованный в соответствии с заданием. Проект демонстрирует применение паттерна MVC и принципов ООП.

## Архитектура

### MVC Паттерн
- **Model**: `Document` - хранит данные о графических примитивах
- **View**: Функции в `main.cpp` - имитируют GUI
- **Controller**: `DocumentController` - управляет бизнес-логикой

### Основные компоненты
- `IShape` - интерфейс для графических примитивов
- `Circle`, `Rectangle` - конкретные реализации примитивов
- `IImport`, `IExport` - интерфейсы для импорта/экспорта
- `Document` - класс документа (модель)
- `DocumentController` - контроллер документа

## Функциональность

- Создание нового документа
- Импорт документа из файла
- Экспорт документа в файл
- Создание графических примитивов
- Удаление графических примитивов

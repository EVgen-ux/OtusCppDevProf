# Курс "C++ Developer. Professional" Домашнее задание №12 "MapReduce”

Проект реализует параллельные вычисления в парадигме MapReduce для анализа больших datasets. Система вычисляет среднее значение и дисперсию цен из CSV файлов с использованием многопоточности.


## Установка и запуск


### Установка из deb пакета

Скачайте .deb пакет, соответствующий релизу. 

Введите следующие команды:

```
sudo dpkg -i  HW12-0.0.X-Linux.deb 
```
(где Х - номер релиза)

### Запуск
```
./mapreduce <filename> <n_mappers> <n_reducers>
```
#### Параметры:

    filename - путь к CSV файлу с данными

    n_mappers - количество mapper потоков

    n_reducers - количество reducer потоков


#### Пример

```
 ./mapreduce ~/input/AB_NYC_2019.csv 6 3
```

### Примечания
- Для лучшей производительности рекомендуется использовать количество mapper'ов равное количеству ядер процессора
- Reducer'ов обычно должно быть меньше чем mapper'ов для эффективной агрегации
